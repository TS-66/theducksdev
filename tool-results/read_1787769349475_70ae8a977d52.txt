    15→## Architecture decisions for this build
    16→
    17→- **Vercel-first**: fully stateless backend. Sessions/workspace/settings live in browser localStorage via zustand persist. No DB.
    18→- `/api/chat` = streaming SSE pass-through proxy to `${baseUrl}/chat/completions` (DeepSeek OpenAI-compatible). Client parses stream + runs agent loop (multi-iteration tool calling) client-side → serverless-safe.
    19→- Virtual workspace FS stored per-session in localStorage; fs/shell tools operate on it. Bash tool = mini shell interpreter over vFS (ls/cat/echo>/mkdir/rm/grep/find/wc/head/tail/tree...).
    20→- Plugin registry mirrors real package names; toggling plugin excludes its tools from request `tools` array.
    21→- Auth: user-provided key in Settings (localStorage), optional env fallback DEEPSEEK_API_KEY on server.
